Лабораторная работа № 4. Обработка массивов. Вариант 26. Автор: Хан Кирилл.

Программа находит наибольший элемент среди строк матрицы, упорядоченных по возрастанию или убыванию. Равные соседние элементы допускаются.

Сначала вводятся целые количество строк и столбцов от 1 до 20, затем все числа матрицы построчно. Дробные числа вводятся через точку. Программа выводит исходную матрицу, подходящие строки и найденный максимум. Если подходящих строк нет, выводится NONE. При ошибке чтения числа или размерах вне диапазона выводится INVALID.

Для запуска нужно открыть Variant26.cpp в консольном проекте C++ в Visual Studio и нажать Ctrl+F5.
